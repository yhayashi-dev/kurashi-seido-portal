# くらしと制度の入口

制度・社会・生活に関する情報サイトと個人開発ツールをまとめるポータルサイトです。

## 構成

- `index.html` トップページ
- `sites.html` サイト一覧
- `updates.html` 更新履歴
- `about.html` 運営について
- `privacy.html` プライバシーポリシー
- `styles.css` 共通デザイン

## ローカル確認

ファイルを直接開くか、次のコマンドで簡易サーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## GitHub Pages

リポジトリの Settings → Pages で、`main` ブランチのルートを公開元に設定します。
